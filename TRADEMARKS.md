# chatbit name and logo

The source code in this repository is free software under the GNU GPL v3 (see `LICENSE.md`).
You may build, modify and distribute it under that licence.

The name "chatbit", the chatbit kitten mascot and the chatbit icons are not part of this
repository and are not licensed under the GPL. Official builds add them from a separate,
private repository; a build made from this repository alone is an unbranded app named
"Chat (unbranded)" with a plain chat bubble icon.

If you distribute your own build:

- do not call it "chatbit" or any confusingly similar name, and do not use the chatbit mascot or
  icons;
- use your own application ID and signing key; you may say that your app is "based on chatbit".

Questions: open an issue on github.com/ledokter/chatbit.
